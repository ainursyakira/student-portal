# a. Student Portal
- Student Portal is a web application designed for students to manage their personal profile, view courses, and track their academic activities. The system provides a user-friendly interface with secure login functionality.

# b. Features
- User registration and login
- Profile management (view personal information)
- Course listing
- Class Schedule
- Tasks List
- Logout functionality
- Responsive design using Bootstrap
- Styled with custom CSS
- Used Chart.js and Script.js
- Client-side JavaScript for enhanced user experience
